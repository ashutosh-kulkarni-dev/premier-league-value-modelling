How we validate
Season-based holdout: train 2023-24, validate 2024-25, test 2025-26. Inside training, GroupKFold on player_id prevents the same player appearing in both folds — stops cross-season leakage. The point model is tuned via Optuna (TPE sampler + MedianPruner, 20-30 trials per booster), then wrapped in MAPIE's cross-conformal regressor for distribution-free 80% prediction intervals. The leakage guard (yaml + runtime assertion + unit test) excludes FM's own value_high, sell_value, and release_clause from the feature set — those are computed by FM's game engine from current_ability/potential/age/contract, so including them would tautologically dominate the model.
