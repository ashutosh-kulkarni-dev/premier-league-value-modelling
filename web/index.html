How we validate
🗓 Split strategy
Train on 2023-24, validate on 2024-25, test on 2025-26. Inside training, GroupKFold on player_id keeps the same player out of both folds — no cross-season leakage.
🎯 Tuning + confidence
Point model tuned with Optuna (TPE sampler + MedianPruner, 20-30 trials per booster). Per-player confidence is the model's backtested median |% error| for the same positional area and value tier — no prediction intervals.
🛡 Leakage guard
YAML + runtime assertion + unit test exclude FM's value_high, sell_value, release_clause. FM derives those from current_ability/potential/age/contract — using them would tautologically dominate the model.
